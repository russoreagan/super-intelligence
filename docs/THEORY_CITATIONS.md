## Not found as a primary source

could not be retrieved through the literature index — in each case because the work is a book or an
edited-volume chapter that predates DOI assignment and is not indexed. A DOI-bearing equivalent by
the same author (or the same claim) is used in the table above, and is what should appear in the
deck.

**None of the 25 theories needs to be relabeled** as "Engineering invariant" or "Ours" on
attribution grounds. Where a substitution was made it is a different work by the same
author advancing the same theory, not a different theory — so the attribution in the deck stands;
only the specific reference line changes.

### Caveat on the book-form originals

The six works in the table above are real and well known, but their *bibliographic details as
written here* (publisher, page range, editor names) come from general knowledge, not from a tool
result. If any of them is quoted directly or cited in a venue that checks references, verify the
edition details against a library catalogue first. The DOI-bearing substitutes carry no such
caveat — those were retrieved and confirmed.
